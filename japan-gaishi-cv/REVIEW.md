## 2. 有問題嘅地方（按殺傷力）

### P0 — 交出去之前一定要改

1. **職稱拼錯 `Architech`**  
   LinkedIn 而家寫住 *Senior Azure Cloud Architech*。Architect 拼錯，對 Architect 職位係即死級。CV、LinkedIn、email signature 一齊改。

2. **如果「呢張 CV」係紙本／螢幕相片**  
   外資 ATS 讀唔到 JPEG/PNG。Recruiter 亦會當你唔認真。只要 **文字 PDF**，檔名例如 `Jackal-Lau-Azure-Architect-Tokyo.pdf`。

3. **職責清單，唔係成績**  
   LinkedIn／典型港式 CV 係「負責 landing zone、cost、migration、AVD」。外資要嘅係：  
   *做咗咩 → 規模幾大 → 結果（錢、風險、時間、穩定性）*。  
   冇數字唔等於冇料，但而家讀起來似 senior engineer 日常，唔似可以 hire 入 Microsoft / Accenture 嘅 architect。

4. **日文能力、日本工作資格空白**  
   就算職係 English-speaking，東京外資幾乎一定問：  
   - Japanese：N1 / N2 / business / conversational / none  
   - Visa：已有工作簽證 / 需要 sponsorship  
   你而家已經喺東京 Johnson Electric 上班，**「Already working in Tokyo / authorized to work in Japan」** 係極大優勢，CV 頂部要寫。日文水平就要誠實；唔好虛報 N2。

### P1 — 令你睇落唔夠「外資 senior」

5. **舊工寫得太長**  
   Dimension Data trainee → associate（2012–2017）不應該同 2022 之後 global landing zone 爭版面。外資只會認真睇最近 6–8 年。再早嘅整段收成 3–4 行。

6. **Summary 太空**  
   「passionate about learning / diversity / sustainability」外資當 filler。第一段要 4 行內講清：Tokyo-based、12+ years、global Azure landing zone + security + FinOps、manufacturing scale、US/EU/SEA。

7. **證照年份可能過期**  
   Azure Solutions Architect Expert（2019）、AWS SAA（2020）而家要年審。過期證照寫上去，technical interviewer 一問就穿。2024 嘅 Security / Cybersecurity Architect / AVD 先放前面；舊證未 renew 就刪或者標 `expired`。

8. **Johnson Electric 故事線未對準外資**  
   JE 係香港上市製造業，唔係 Silicon Valley 品牌。對外資要強調：  
   **global manufacturing、多區（US/EU/SEA）vWAN、landing zone、security policy、AVD、Siemens PLM on Azure、Cloud COE**。  
   唔好寫到似「HK 公司內部 IT」。Tokyo 調任本身係 plus，要寫 *relocated to Tokyo to lead platform architecture*。

9. **Education 位置**  
   IVE + 公開大學兼讀學位，senior 職位唔會因為呢樣出局，但**唔好放第一頁最頂**。外資 architect 職先睇 cert + 最近經驗。

### P2 — 小但會減分

10. 舊 bullet 有 `tie3`（應為 tier-3）、亂碼符號（`•`）——CV 匯出時好易一齊出現。  
11. Check Point SandBlast Mobile 等舊證，除非 apply 網絡安全 vendor，否則唔好佔行。  
12. 冇 LinkedIn URL、檔名、電話區號（+81）。  
13. 一 CV 打天下：Microsoft CSA、Accenture、Siemens Japan 關鍵字唔同，最少準備 **platform / security / consulting** 三個微調版。

## 4. 你要填嘅數字（填完 PDF 先好大量投）

改寫稿用咗公開 LinkedIn 字眼，**冇估數**。你補到以下任何幾項，殺傷力即升：

- Azure：幾個 subscription / management group、幾個 region、大約幾多 VM / AVD host / user
- 錢：一年 cloud spend 量級、你 optimize 咗幾多 % 或幾多 USD
- vWAN：幾條 region hub、幾間工廠/office 接通
- 遷移：幾多 workload / 幾間 country DC
- Policy：幾個 custom policy、non-compliance 降咗幾多
- 人：COE 教咗幾多人、而家 team 幾大
- 可用性：重大 incident 降幅、patch / DR 結果
- 日文：JLPT 級別或「daily stand-up 用英文 / 可以讀日文 ticket」
- Visa：在留資格名稱即可（例：技術・人文知識・国際業務）

唔好把公司內部 hostname、subscription ID、tenant ID 寫上 CV。

## 7. 交 CV 前 checklist

- [ ] PDF，唔係相片；英文；最多 2 頁
- [ ] Architect 拼對；檔名有名 + Tokyo + Azure
- [ ] 頂部有 Tokyo + work authorization + Japanese level
- [ ] 最近 JE 經驗有數字；2017 之前大幅壓縮
- [ ] 證照只留有效／已 renew
- [ ] 冇相片、年齡、婚姻、血型、家庭
- [ ] LinkedIn 同 PDF 職稱、日期一致
- [ ] 用公司 JD 微調 keyword（Landing Zone、CAF、Zero Trust、FinOps、AVD、Entra ID）

**一句话：** 唔係「唔好用呢張 CV」，而係「呢張（港式職責清單 / 可能仲係相片）唔 fit 大型外資」。用呢份英文 2 頁稿 + 你自己填數字，先對得正你想入嗰批公司。
