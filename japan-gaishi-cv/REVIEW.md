### 4) 兩欄 Word layout — ATS 不友善

左欄 section title、右欄正文。抽文字會變成：

`Professional Summary System Analyst with 8+ years…`

Workday / Greenhouse / Taleo 常見讀亂。視覺幾靚，**機器分唔到標題同內文**。外資網申多數行 ATS。要單欄、標準 heading、無 text box。

### 5) 全部係職責，0 個數字

SFC 九條 bullet 全部 *Gather / Design / Develop / Manage*。大型外資要：

*做咗咩 → 服務邊類 user / 數據量級 → 結果*

Vertex AI / GenAI 如果唔寫 **邊個 use case**（內部搜尋、RAG、報告問答？），面試官會當 buzzword。

### 6) 日文 Beginner + 無簽證狀態

對東京大型外資：英文職存在，但 **Beginner 會大幅收窄**。可以投 English-first data/BI，要寫明：

- Japanese: Beginner（誠實，啱）  
- Work authorization: 已有工作權 / 配偶簽 / 要 sponsorship  

而家 CV 完全冇簽證一行。人喺 Koto 係 plus，但 HR 唔知要唔要 sponsor。

### 7) 職稱 `System Analyst` 對唔準外資 JD

香港/澳洲常用；美國/歐洲/日本外資 data 職多數叫：

- Data Analyst / BI Analyst  
- Analytics Engineer  
- Data Engineer  

你實際做 BI + ETL + 少少 GenAI integration。用 **System Analyst** 會被配去 IT support / 業務分析，而唔係 data 職。建議 headline：`Data & Analytics Engineer` 或 `BI / Data Analyst (Applied GenAI)`。
